📊 Statistics & Mathematics for AI/ML – Jupyter Notebook Study Material
📖 Overview
This repository contains a complete set of Statistics notebooks created as study material for learning the statistical concepts required in Artificial Intelligence (AI) and Machine Learning (ML).

Each notebook explains a specific topic using:

Definitions
Formulas (where applicable)
Real-world examples
Python implementations
Business and AI/ML examples
Interpretation of results
A common sample dataset is included to practice the concepts throughout the notebooks.

▶️ How to Run
Clone this repository.
git clone <repository-url>
Navigate to the project folder.
cd Statistics-Notebooks
Install the required libraries.
pip install pandas numpy matplotlib scipy scikit-learn statsmodels
Launch Jupyter Notebook.
jupyter notebook
Open any notebook and run the cells.

Analyze feature relationships.
